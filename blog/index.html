前置準備

必要工具

  1. Node.js

    • 建議版本：v14.0.0 或更高
    • 安裝方式：
      • Windows：從官網下載安裝檔
      • 確認安裝：node -v

  2. Git

    • 建議版本：2.0.0 或更高
    • 安裝方式：
      • Windows：從官網下載安裝檔
      • 確認安裝：git --version

常用指令

指令 功能說明 使用時機
hexo new 文章名稱 建立新文章 撰寫新文章時
hexo server 啟動本地預覽 開發時預覽
hexo generate 產生靜態檔案 部署前
hexo clean 清除快取 遇到問題時
hexo deploy 部署網站 發布更新時

常見問題

1. 文章無法顯示

  • 檢查 _config.yml 中的 permalink 設定
  • 確認文章 front-matter 格式正確

2. 主題無法套用

  • 確認主題目錄名稱正確
  • 檢查 _config.yml 中的 theme 設定

3. 部署失敗

  • 確認 Git 設定正確
  • 檢查部署平台的設定

  1. 建立 GitHub Repository

    • 建立一個名為 你的使用者名稱.github.io 的倉庫
    • 例如：如果 GitHub 使用者名稱為 johndoe，則倉庫名稱為 johndoe.github.io

注意事項

  • 確保 GitHub 倉庫名稱與 _config.yml 中的 url 設定相符
  • 首次部署可能需要設定 GitHub 認證
  • 部署後可能需要等待幾分鐘才能看到更新
  • 如果使用自訂網域，需要設定 DNS 記錄指向 GitHub Pages
